# 청해 대화 음성

두 사람 이상이 말하는 청해 문제(즉시응답 · 과제이해 · 포인트이해 · 통합이해 · 장면 대화)의 대사를 미리 녹음한 파일입니다.
혼자 말하는 문제(개요이해 등)와 단어 듣기 · 예문은 기기의 음성(TTS)으로 읽습니다.

- 파일: `청해id/키.mp3` (intro = 안내, l줄 = 대사, q질문 = 질문, o질문-보기 = 보기), 보기 번호는 `num/목소리-번호.mp3`
- 목록: `clips.js` (녹음 스크립트가 만든 파일 — 직접 고치지 않음)
- 음성 합성: Style-Bert-VITS2
- 목소리 모델: litagin/style_bert_vits2_jvnv (jvnv-F1-jp · jvnv-F2-jp · jvnv-M1-jp · jvnv-M2-jp) — JVNV 코퍼스로 학습, CC BY-SA 4.0
- 이 폴더의 음성 파일도 CC BY-SA 4.0을 따릅니다.
